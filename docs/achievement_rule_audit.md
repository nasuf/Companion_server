# Achievement Rule Audit

审计日期：2026-06-01

范围：`app/services/achievements/*`、聊天/记忆/主动消息 hook、每日 rollup。结论里的“实时”表示发送消息或记忆写入后立即判断；“日终”表示完整自然日结束后判断，避免“全天/两天/全部”类条件提前误触发。

数据隔离原则：所有成就解锁和统计事件以 `user_id + agent_id` 为主键维度；`workspace_id` 仅用于路由、查询记忆归属和通知上下文，不把不同 agent 的数据混到一起。

## Remaining Semantic Dependencies

- 记忆类成就依赖记忆抽取和分类质量；触发点已经绑定到用户记忆分类，而不是聊天关键词。
- 当前状态/未来计划/高情绪类首次触发仍使用轻量 cue 或情绪估计器；已经尽量保守，但未来若意图识别结果稳定落库，可以替换为意图事件进一步降低误触发。
- 第 56 条文档写死 `23:00-07:00`，因此保留固定睡眠时段；第 48/74/93 使用真实作息状态事件。
